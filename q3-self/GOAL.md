# Q3: чи може кристал тримати власний ритм, читаючи власне минуле, і чия це точність?

## Що тут називається «читати себе»

Кристал той самий, що в [Q2](../q2-crystal/GOAL.md): N = 32, під тягою F, при σ = 0,3, без гіроскопа. Фізику скопійовано з `q2-crystal/run.py`. Тест `test_alone_is_q2_crystal_autonomous_clock` перевіряє, що без зворотного зв'язку траєкторії збігаються біт у біт.

Тепер кристал читає власну середню фазу Φ і править власну тягу:

    F(t) = F − k · (Φ(t) − Φ(тоді) − v*·τ)

Тобто: «від того моменту я мав просунутися на v*·τ; якщо просунувся більше — пригальмую, менше — підтягнуся». Ритм світу (Q2) тут відсутній. Питання в тому, звідки береться «тоді».

| опора | «тоді» | що це фізично |
|---|---|---|
| `alone` | — (k = 0) | автономний годинник |
| `ideal` | рівно t − τ | ідеальна лінія затримки. Вона безкоштовно знає час світу: це прихований годинник симулятора |
| `memory` | момент, коли **другий кристал** (пам'ять: N_mem вузлів, автономний, та сама фізика, свій шум) стояв на n·π власної фази позаду | лінія затримки, чий час тримає кристал. Фаза основного кристала записується на кожному підкроці й шукається за фазою пам'яті |

Проміжок рахується в **тіках**: тік — це проковзування на період пінінгу π. Для `ideal` τ = n·π / v*; для `memory` проміжок M = n·π власної фази пам'яті.

## Що каже лінійна теорія

Для осцилятора з запізнювальним зворотним зв'язком (Goldobin, Rosenblum, Pikovsky, *Phys. Rev. E* 67, 061119, 2003) дифузія фази падає як D / (1 + aτ)², де a = k·dv/dF.

Якщо «тоді» визначає пам'ять зі своєю дифузією D_mem, те саме інтегрування дає:

    D_основного = [(aτ)²·D_mem + D] / (1 + aτ)²

- **Ідеальна пам'ять** (D_mem = 0): виграш (1 + aτ)², росте з довжиною пам'яті без межі. Точність бере прихований годинник лінії затримки.
- **Пам'ять-кристал:** коли aτ ≫ 1, основний кристал **успадковує точність пам'яті**, і довжина проміжку перестає мати значення.
- **Пам'ять того самого розміру** (D_mem = D): (1 + x)² / (1 + x²) ≤ 2. Найбільше, що можна виграти, — усереднення двох однакових годинників.

## Що показало калібрування (seeds з окремого простору імен, у вердикт не входить)

`calibration/*.txt`: по 256 траєкторій; G = D(alone) / D(клітинки). D рахується як нахил дисперсії між лагами 300 і 1000.

- **Розмір.** N = 8 / 32 / 128 тримають час з D_time = D/v² = 3,3 · 10⁻² / 9,7 · 10⁻³ / 2,4 · 10⁻³. Тобто точність росте приблизно як N, а v однакова (0,488–0,491).
- **dv/dF ≈ 0,78** при F = 1,3.
- **Ідеальна пам'ять** (k = 0,32): 1 тік — G = 5,7, 4 тіки — G = 75.
  - При більшому k і 16 тіках зворотний зв'язок стає нестійким (обрізання тяги до 47%). Тому k = 0,32.
  - На довжині рівно в 1 тік при k = 1,28 виграш падає до 8,7.
- **Пам'ять-кристал, 4 тіки, k = 0,32:** N_mem = 8 — G = 0,44 (гірше, ніж без пам'яті); N_mem = 32 — 1,29; N_mem = 128 — 5,3.
- **Знахідка калібрування: пам'ять-кристал читається цілими тіками.**
  - Перший прогін читав пам'ять на 3,9 рад (1,24 тіка). Пам'ять N = 128 тримала час з D_time 2,0 · 10⁻³, а основний кристал — лише 5,0 · 10⁻³.
  - Тоді я перевірив вказівник іншими пам'ятями (`calibration/pointer.txt`):
    - ідеальний годинник через той самий вказівник дає G = 171;
    - броунівська пам'ять з тим самим D_mem передає 0,85 своєї дифузії, рівно за теорією.
  - Отже, зайвий шум — від самого кристала: всередині тіку його фаза йде нерівномірно (пінінг має період π).
  - На 4 тіках основний кристал успадковує точність пам'яті N = 128 (G = 5,3). На 4,5 тіка — лише 1,9.

**Як рахуються інтервали.** Інтервали 95% беруться з 2000 повторних вибірок траєкторій кожної клітинки (квантилі без інтерполяції); bootstrap засіяно від id реєстрації. D = [var(Φ(t2) − Φ(t0)) − var(Φ(t1) − Φ(t0))] / (2 (t2 − t1)). Це нахил дисперсії, тож обмежене тремтіння навколо утримуваного ритму скорочується. Це урок H1 з Q2.

## Що цей дослід не стверджує

- **Буфер історії тут безкоштовний і точний.** Значення фази основного кристала зберігаються без шуму й без ціни. Пам'ять-кристал тримає лише **час**, за яким їх шукають. Справжня пам'ять значень теж коштувала б.
- **Одне k, одна тяга, одна температура.** Межу стійкості по k·τ виміряно лише грубо (калібрування).
- **Ентропію пам'яті записано, але гіпотез про неї немає.** Ефективність η з нею й без неї — описова.
- **Дослід не каже, що ШІ потрібна така пам'ять.** Він питає, чия точність у системи, яка тримає ритм, читаючи себе.
