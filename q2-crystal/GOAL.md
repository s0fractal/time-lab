# Q2: чи тримає солітонний кристал ритм світу, і чи це колективна властивість?

## Що тут називається годинником

Кристал — це решітка `lab` (ARCHIVED / NOT CURRENT PRECEDENT: `phs-soliton/phs/core.py`, тут переписана в numpy без імпорту). Це N вузлів по d = 2 фази на колі, з пінінгом sin(2θ), зв'язком сусідів g_lat, «увагою» κ і термостатом при температурі σ². Ненавчена: жодної задачі, лише фізика.

- **Без накачки кристал не тікає.** У рівновазі (F = 0) середня швидкість фаз дорівнює нулю, і дифузія теж (калібрування: v = 0, D = 0). «Годинник» у `lab` був перехідним обертанням сигналу пам'яті, поки той згасав, тобто циферблатом, що зупиняється.
- **Годинник = кристал під сталою тягою F.** Фази проковзують через бар'єри пінінгу, і кожне проковзування на π — тік. Платить він ентропією: Σ = F·v / σ².
- **Ціна точності.** Для автономного годинника ефективність η = v² / (D·Σ) обмежена межею TUR ≈ 1. Калібрування: без гіроскопа кристал будь-якого розміру тримається біля межі (η ≈ 0,8–1,1). З гіроскопом `lab` великий кристал (N ≥ 16) падає до η ≈ 0,2.
- **Ритм світу.** Тяга модулюється: F + F1·sin(ωt). Захоплений кристал іде рівно з частотою світу (v/фазу = ω/2), і його дифузія падає в G разів. G — **виграш захоплення**, головна величина цього питання.

## Що показало калібрування (seeds з окремого простору імен, у вердикт не входить)

`calibration/calibration-lock.*`: γ = 2, F = 1,3, F1 = 0,6, ω = 1; по 512 траєкторій.

| G | N = 2 | N = 8 | N = 32 |
|---|---|---|---|
| кристал, σ = 0,3 | 2,0 | 105 | 2614 |
| ті самі осцилятори без зв'язку, σ = 0,3 | 1,5 | 1,5 | 1,6 |
| кристал, σ = 0,5 | 1,4 | 1,8 | 20 |
| без зв'язку, σ = 0,5 | 1,0 | 1,2 | 1,3 |

Окремий осцилятор ритм майже не тримає. Кристал тримає, і що він більший, то сильніше.

## Гіпотези (`registration.json`)

| | твердження | правило |
|---|---|---|
| H1 | більший кристал тримає ритм тугіше: при σ = 0,3 G щонайменше подвоюється від N = 2 до 8 і знову від 8 до 32 | supported, якщо обидва інтервали log10-відношень вище log10 2; contradicted, якщо будь-який цілком нижче |
| H2 | захоплення колективне: при N = 32, σ = 0,3 G зв'язаного кристала щонайменше в 10 разів більший, ніж у тих самих осциляторів без зв'язку | інтервал log10 G(кристал)/G(без зв'язку) вище 1 |
| H3 | розмір дає стійкість до шуму: при σ = 0,5 G(N = 32) щонайменше в 5 разів більший за G(N = 8) | інтервал вище log10 5 |
| H4 | гіроскоп `lab` (j_scale 0,1) послаблює захоплення щонайменше вдвічі (N = 32, σ = 0,3). **Не калібровано: прогноз наосліп** | інтервал log10 G(j = 0,1)/G(j = 0) нижче −log10 2 |

Інтервали — 95% перцентильні, з 2000 повторних вибірок траєкторій кожної клітинки; bootstrap засіяно від id реєстрації.

## Дизайн

- **Клітинки:** 26. Зв'язок {кристал, без зв'язку} × N {2, 8, 32} × σ {0,3; 0,5} × F1 {0; 0,6}, плюс кристал N = 32, σ = 0,3 з гіроскопом.
- **Траєкторії:** 1024 на клітинку, вікно [150, 600] одиниць часу.
- **Фізика:** γ = 2, F = 1,3, ω = 1; інше — як ініціалізація `lab`.
- **Seeds:** H(id реєстрації ‖ раунд маяка ‖ назва клітинки). Гіроскоп W — із seed `crystal`.
- **Аналіз:** `analyze.py`. Контролі в `tests/`: 9 синтетичних, наскрізний прогін справжнім runner-ом, 7 мутантів, усі вбиті на assertion.

## Що цей дослід не стверджує

- Він не каже, що ШІ потрібен такий годинник. Він каже, чи є в цієї фізики властивість «тримати ритм світу колективно».
- Одна частота ω, одна амплітуда F1, одна тяга F. Ширину вікна захоплення по F тут не міряно.
- Переданий годиннику ритм — це зовнішня модуляція. Тож η > 1 у захопленому стані не порушує TUR, а показує, що точність прийшла ззовні.
