# time-lab: правила для агентів

- Кожне питання — окремий каталог верхнього рівня з `GOAL.md`. Новий дослід не змінює чужих каталогів.
- Підтверджувальні дані збираються лише після того, як реєстрацію подано в `.warrant/`, закомічено й запушено. Seeds виводяться з id реєстрації та раунду маяка ([METHOD.md](METHOD.md) §3). Зміна після push — це нова версія реєстрації з причиною; старі дані лишаються у звіті.
- Вердикт гіпотези — це закривальна версія `prediction@1`, яку підтвердив attest від `time-lab-decider` з кодом, названим у реєстрації. Прозовий звіт його не замінює.
- Підписуй записи лише як свій актор і своїм ключем. Seeds ніколи не лежать у репозиторії. Seed `time-lab-decider` тримає оператор claude поза репозиторієм; так і пиши в провенансі.
- Стан прогонів зберігається в git (малі JSON) або в ignored `runs/`, ніколи не в `/tmp`. Локальні моделі запускаються по одній: пам'ять машини спільна.
- Перед тим як будувати checker, runner мутантів або claims-документ, прочитай `~/Projects/primitives/PATTERNS.md`.
- Посилання на архівований `lab` мають позначку ARCHIVED / NOT CURRENT PRECEDENT.
- Публікація назовні (публічний репо, DOI, препринт) — окреме рішення власника.
