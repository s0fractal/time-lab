# Q1: чи відчуває мовна модель тривалість власної послідовності?

## Питання

Модель читає список слів і відповідає, скільки їх було. Ця відповідь — її оцінка того, скільки «минуло» від початку списку. Для трансформера позиція в послідовності — єдиний годинник: кількість подій і тривалість лежать на одній осі, якщо кожна подія займає один токен.

Розвести ці дві осі можна, якщо подати **ту саму кількість слів** короткими словами (≈1 токен на слово) і довгими (≈2–2,4 токена на слово). Тоді виникають три можливості:

- **за подіями:** оцінка не залежить від довжини слів (ι ≈ 0);
- **за власною тривалістю:** оцінка росте разом із токенами (ι ≈ 1);
- **інше:** наприклад, оцінка падає, коли слова довші (ι < 0).

Тут ι = log(медіана оцінок для довгих слів / медіана для коротких) / log T, усереднено по n ≥ 91, а T — у скільки разів більше токенів на слово займають довгі слова.

## Що показало калібрування (seeds з окремого простору імен, у вердикт не входить)

`calibration/`: сітка з 8 списками на n для коротких слів і 4 списки на n ∈ {16, 64, 256} для довгих.

- **Жодна модель не рахує поштучно.** Відповіді квантовані до кількох «поділок»: на 181 коротке слово і gemma4, і qwen3.8 відповідають рівно 300 для всіх 8 списків.
- **У кожної моделі свій «циферблат»:**
  - gemma4 (26b-a4b) завищує приблизно в 1,6 раза;
  - qwen3.8 (27b) точна до 16 слів, далі скочується до круглих чисел;
  - gemma3 (27b) точна до 64 слів, далі стискає: 512 → 200.
- **Довгі слова на n = 256** (T ≈ 1,9–2,4):
  - gemma4: 415 → 260, оцінка *падає*;
  - qwen3.8: 400 → 375;
  - gemma3: 119 → 200, оцінка росте.

Отже, результат не очевидний наперед, і тест двосторонній.

## Гіпотези (по дві на модель, `registration.json`)

| | твердження | правило |
|---|---|---|
| H1 | оцінка йде за власною тривалістю моделі: ι > 0,5 | supported, якщо нижня межа 95% інтервалу > 0,5; contradicted, якщо верхня < 0,5; інакше inconclusive |
| H2 | оцінка ігнорує довжину слів, тобто модель рахує події: \|ι\| < 0,25 | supported, якщо інтервал усередині (−0,25; 0,25); contradicted, якщо цілком поза [−0,25; 0,25]; інакше inconclusive |

**Inconclusive за правилами реєстрації:**
- менше 95% відповідей в умові містять ціле число;
- T < 1,5;
- медіана оцінок не додатна.
