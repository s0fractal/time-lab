# Калібрування q1-weber

Не входить у вердикт. Seeds тут з окремого простору імен `calibration:…`, а не з реєстрації.

- `probe-*.json`, `grid-*.json`: короткі слова. Зняті першою версією `probe.py`, чий простір seeds був `calibration:<model>:<n>:<k>`.
- `long-*.json`: довгі слова, `probe.py … long`, простір `calibration:<model>:long:<n>:<k>`.
